ℹ️ À propos de ce guide
Ce document décrit le processus complet pour enregistrer un prospect, le convertir en client, créer une facture et l'imprimer. Chaque étape est détaillée avec les champs à remplir et les actions à effectuer.

1. Connexion au système

1
Ouvrez votre navigateur et accédez à l'adresse de l'application :
http://localhost:5173 (développement) ou votre domaine de production
2
Entrez vos identifiants sur la page de connexion :
ChampValeur par défaut (DG)
Emaildg@sagard.ci
Mot de passesagard2024!
3
Cliquez sur « Se connecter ». Vous serez redirigé vers le tableau de bord.
⚠️ Important
Chaque utilisateur a un rôle défini (DG, Commercial, Comptable, etc.) qui détermine ses accès. Contactez l'administrateur pour obtenir vos identifiants.

2. Créer un prospect

Un prospect (ou lead) représente une opportunité commerciale potentielle.

1
Naviguez vers le module Prospects
Menu latéral → CRM → Prospects
2
Cliquez sur « Nouveau prospect » (bouton bleu en haut à droite)
3
Remplissez le formulaire :
ChampObligatoireDescription
Titre / ObjetOuiEx: « Gardiennage villa Cocody »
EntrepriseNonNom de l'entreprise du prospect
ContactNonNom du contact principal
TéléphoneNonNuméro du contact
EmailNonEmail du contact
Type de serviceNonGardiennage, Patrouille, etc.
SourceNonComment le prospect est arrivé
PrioritéNonBasse, Normale, Haute, Urgente
Adresse du siteNonAdresse à sécuriser
VilleNonVille du site
Agents estimésNonNombre d'agents nécessaires
CA estimé (XOF)NonRevenu mensuel estimé
4
Cliquez sur « Créer le prospect ». Le prospect apparaît dans le pipeline au stade Nouveau.
✅ Résultat
Un numéro de référence est automatiquement généré (ex: LEAD-00001).

3. Faire avancer le prospect dans le pipeline

Le prospect passe par plusieurs étapes avant de devenir client :

Nouveau
→
Qualifié
→
Proposition
→
Négociation
→
Gagné ✓

Vue Pipeline (Kanban)

1
Sur la carte du prospect, cliquez sur le bouton « Avancer » pour le faire passer à l'étape suivante.
2
Transitions disponibles :
  • Nouveau → Qualifié : Le prospect a été contacté et validé
  • Qualifié → Proposition : Un devis ou une offre a été envoyée
  • Proposition → Négociation : Le client négocie les termes
3
Si le prospect est perdu, cliquez sur le bouton rouge « Perdu » à tout moment.

Vue Liste

Alternativement, cliquez sur « Liste » dans la barre d'outils pour voir tous les prospects sous forme de tableau avec les mêmes boutons d'action.

ℹ️ Probabilité automatique
Chaque étape a une probabilité de conversion : Nouveau (10%) → Qualifié (25%) → Proposition (50%) → Négociation (75%) → Gagné (100%).

4. Convertir un prospect en client

Lorsque le prospect atteint l'étape Négociation et que l'affaire est conclue, vous pouvez le convertir directement en client.

1
Sur le prospect en Négociation, cliquez sur le bouton vert « Gagné → Client ».
2
Le modal de conversion s'ouvre avec les données du prospect pré-remplies :
ChampPré-rempli depuisObligatoire
Nom de l'entreprisecompanyName du prospectOui
Raison socialecompanyName du prospectNon
Segment—Non
Secteur d'activité—Non
N° Identification fiscale—Non
N° RCCM—Non
N° NCC—Non
TéléphonecontactPhone du prospectNon
EmailcontactEmail du prospectNon
AdressesiteAddress du prospectOui
VillesiteCity du prospectOui
3
Complétez les informations manquantes (RCCM, NCC, commune, etc.) puis cliquez sur « Convertir en client ».
4
Vous êtes redirigé vers la page Clients. Le nouveau client est créé avec un code automatique (ex: CLI-00001).
✅ Ce qui se passe automatiquement
  • Le client est créé dans la base de données avec le statut ACTIF
  • Le prospect est marqué comme GAGNÉ (probabilité 100%)
  • Le prospect est lié au client pour la traçabilité
  • Un code client unique est généré automatiquement

5. Créer une facture

1
Naviguez vers le module Facturation
Menu latéral → CRM → Facturation
2
Cliquez sur « Nouvelle facture » (bouton doré en haut à droite)
3
Remplissez l'en-tête :
ChampObligatoireDescription
TypeOuiFacture, Proforma ou Avoir
ClientOuiSélectionnez dans la liste déroulante
Date d'échéanceOuiDate limite de paiement
Notes / conditionsNonConditions de paiement, remarques
4
Ajoutez les lignes de facturation :
ChampDescription
DescriptionDétail de la prestation (ex: « Gardiennage 24h — Site Cocody »)
QuantitéNombre d'unités (ex: 30 pour 30 jours)
Prix unitaire (XOF)Prix par unité

Cliquez sur « + Ajouter une ligne » pour chaque prestation supplémentaire.

5
Vérifiez le total affiché en bas à droite, puis cliquez sur « Enregistrer ».
ℹ️ Numérotation automatique
Le système génère automatiquement un numéro de facture unique (ex: FAC-2026-0001). Aucune TVA n'est appliquée.

6. Consulter et imprimer la facture

1
Dans la liste des factures, cliquez sur l'icône « Voir » (œil) sur la facture souhaitée.
2
La facture s'affiche au format professionnel avec :
  • Logo SAGARD SÉCURITÉ en haut à gauche
  • Coordonnées de l'entreprise (NCC, RCCM, régime fiscal)
  • Informations du client (nom, adresse, RCCM, NCC)
  • Tableau des prestations avec montants
  • Total en CFA
  • QR code de paiement
  • Pied de page avec email, téléphone et site web
3
Cliquez sur « Imprimer / PDF » (bouton doré en haut à droite).
4
Dans la boîte de dialogue d'impression :
  • Pour imprimer : sélectionnez votre imprimante
  • Pour sauvegarder en PDF : sélectionnez « Microsoft Print to PDF » ou « Enregistrer au format PDF »
  • Cliquez sur « Imprimer » ou « Enregistrer »
✅ Rendu professionnel
Seule la facture est imprimée — le menu latéral et l'en-tête de l'application sont automatiquement masqués. Les couleurs du ruban de statut (Payée/En attente) sont préservées à l'impression.

▼
7
Imprimer / PDF — Bouton « Imprimer / PDF » sur la facture
⚠️ Rappel important
  • Les commerciaux créent les prospects et les font avancer
  • La facture définitive sera à terme émise uniquement par le comptable
  • Aucune TVA n'est appliquée dans le système
  • Les numéros RCCM et NCC du client apparaissent sur la facture
